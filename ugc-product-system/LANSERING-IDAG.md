# Lansering idag — timme för timme, sedan 30 dagar

Förutsättning: en dator/telefon, 0 kr, prompterna i [PROMPTS.md](PROMPTS.md). Allt nedan är gratisverktyg.

## Dag 1 (idag) — från noll till live tratt, ca 5–6 timmar

### Timme 1 — Infrastruktur (konton)
- [ ] Skapa konto på **Lemon Squeezy** (rekommenderas: sköter EU-moms som merchant of record; alternativ: Gumroad).
- [ ] Skapa konto på **MailerLite Free** (e-postautomation, gratis till 1 000 prenumeranter).
- [ ] Skapa **TikTok- + Instagram-konto** för varumärket. Namnformel: `ugc + [nyckelord]` (t.ex. "ugcstartsverige"). Enkel logotyp/banner i Canva Free, 10 min, inte mer.
- [ ] Bio på båda: en mening om vad följaren får + länk (Lemon Squeezys gratis butikssida eller Carrd Free som länksida).

### Timme 2 — Lead magnet
- [ ] Kör prompt **A1** → granska → layouta i Canva → exportera PDF.
- [ ] Ladda upp i MailerLite som "freebie vid signup" (landningssida ingår i gratisplanen).

### Timme 3 — Första betalprodukten
- [ ] Kör prompt **A2** (UGC Pitch Pack, 129 kr) → klistra in i ett snyggt Google Doc/Notion.
- [ ] Skapa produkten i Lemon Squeezy, pris 129 kr. Säljtext: prompt **B1**.
- [ ] Testköp med 100 %-rabattkod på dig själv — verifiera att leveransen fungerar.

### Timme 4 — Koppla tratten
- [ ] MailerLite: automation "ny prenumerant → leverera PDF → dag 0-mejl med Pitch Pack-erbjudande" (mejl 0 från prompt **B2**; resten av sekvensen byggs dag 5–7 — dag 0 räcker för lansering).
- [ ] Länk i bio → MailerLites signupsida. Testa hela kedjan själv: klick → signup → PDF → mejl.

### Timme 5–6 — Första innehållet
- [ ] Kör prompt **C1** men be om **5 skript** (inte 25) för dag 1.
- [ ] Spela in 3–5 videor på telefonen (ansikte valfritt — text-overlay + skärm/B-roll fungerar). Klipp i CapCut.
- [ ] Publicera 2 st idag (1 TikTok, 1 Reel), schemalägg resten till imorgon.
- [ ] **Lanseringen är live.** Tratten kan nu generera prenumeranter och sälj medan du bygger vidare.

## Dag 2–4 — Kärnprodukten
- [ ] Prompt **A3** → bygg **UGC Starter System** i Notion (duplicerbar länk = leveransen), kalkylatorn i Google Sheets.
- [ ] Lägg upp för 499 kr, säljtext via **B1**.
- [ ] Fortsätt publicera 3 videor/dag (skripten från C1). Svara på ALLA kommentarer — dag 2–14 är kommentarerna din marknadsundersökning.

## Dag 5–7 — Hela maskinen
- [ ] Prompt **A4** → premiumpaketet 1 290 kr. Prompt **A5** → order bump 79 kr på kassan.
- [ ] Färdigställ 7-dagars mejlsekvensen (**B2**) i MailerLite.
- [ ] Aktivera **affiliateprogrammet** (inbyggt i Lemon Squeezy/Gumroad): 40 % provision.
- [ ] Sätt upp det automatiska dag 3-mejlet till köpare (**C3**) — det är detta som startar tillväxtloopen.

## Dag 8–30 — Motor-drift (~1 h/dag + en batchdag/vecka)
- **En batchdag/vecka:** prompt **C1** → 25 skript → spela in/klipp alla → schemalägg 3–5/dag.
- **30 min/dag:** svara på kommentarer/DM. Kör prompt **C2** varje söndag — nästa veckas innehåll byggs på veckans faktiska frågor.
- **Dubblera på vinnare:** en video som går över ~10 000 visningar → gör 3 varianter av den inom 48 h.
- **Varje kund** får affiliate-inbjudan automatiskt. Följ upp manuellt med de som säljer — ge dem färdigt materialpaket (klipp, hooks, länkar).
- **Vecka 4:** höj det som fungerar, döda det som inte gör det. Titta bara på tre siffror: prenumeranter/dag, konvertering till första köp, AOV.

## Milstolpar och ärliga förväntningar

| Milstolpe | Typiskt tidsfönster |
|---|---|
| Första prenumeranten | Dag 1–3 |
| Första försäljningen (129 kr) | Dag 3–14 |
| Första 499 kr-försäljningen via mejlflödet | Vecka 2–3 |
| 500–2 000 kr/dag | Månad 1–3 (kräver daglig publicering) |
| 10 000 kr/dag | Kräver att loopen fått fäste: viral räckvidd och/eller 10+ aktiva affiliates. Kan ta 3–12 månader. Är inte garanterat — men systemet är dimensionerat för det. |

**Om det går trögt vecka 2–3:** problemet är nästan alltid innehållet, inte produkten. Kör C2-prompten hårdare, testa nya hooks, publicera mer. Lista + produkter + affiliates är tillgångar som ackumuleras — varje dag systemet körs blir nästa dag lite lättare.
